# MeshCore ⇄ MAX Bridge

Windows GUI-приложение на Python, которое связывает **MeshCore** (LoRa mesh-сеть) с мессенджером **MAX**. Сообщения из каналов MeshCore автоматически пересылаются в указанные MAX-чаты, а ответы из MAX уходят обратно в эфир — с учётом лимитов, очереди и контроля состояния ноды.

---

## Возможности

- 🔗 **Двусторонняя пересылка** — Mesh → MAX и MAX → Mesh
- 📡 **Привязка каналов** — каждому каналу MeshCore свой MAX-чат (с комментарием для наглядности)
- ⏳ **Rate-limiter с очередью** — сообщения не отбрасываются, а встают в очередь с резервированием времени отправки
- 📊 **Статистика в реальном времени** — батарея, uptime, RSSI, SNR, очередь ноды, пакеты
- 🩺 **Детектор «зомби»** — если нода перестаёт отвечать, LED Mesh становится оранжевым
- 🎨 **Анимации** — пульсирующие LED, полоски активности эфира
- 💾 **Персистентность** — все настройки и привязки сохраняются в `mesh_max_config.json`
- 🔌 **Выбор COM-порта** — из списка подключённых устройств, с автосохранением последнего
- 🛑 **Корректная остановка** — COM-порт всегда освобождается, кнопки не залипают

---

## Требования

- **Windows 10/11**
- **Python 3.10+**
- **MeshCore-нода**, подключённая по USB (Heltec, RAK, LilyGO и т.п.)
- **MAX-бот** — токен от [@MasterBot](https://max.ru) (или через бизнес-кабинет MAX)
